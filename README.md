⚔️ Turn-Based RPG Game (Isekai Generico Game)
A turn-based command-line RPG game written in C. Features dynamic memory allocation, function pointers for spell casting, and a custom inventory and reward system.

🎮 Game Overview
You are summoned by Aqua, the goddess of this world, to defeat the Demon King and save the land.

Key Features
Character Customization: Name your hero and select 3 starting spells from a pool of 5 magic abilities.
Turn-Based Combat: Battle through 4 increasingly difficult enemies:
Kobold
Dark Elf
Dragon
Demon King (Final Boss)
Combat Mechanics:
Physical Attack: Deals damage based on physical stats.
Magic: Cast offensive, defensive, or healing spells.
Inventory System: Use or manage items that grant permanent stat boosts.
Evasion: 50% chance to dodge the incoming attack.
Loot & Rewards: Receive random treasure chests after victories to upgrade your inventory.
🛠️ Requirements
C Compiler: gcc (MinGW for Windows, Clang for macOS/Linux) or any standard C compiler.
IDE / Editor: Visual Studio Code, CLion, or terminal execution.
🚀 How to Run
Method 1: Using VS Code Terminal (Windows / PowerShell)
Open the project folder in VS Code.
Ensure your terminal encoding supports special characters:
chcp 65001
